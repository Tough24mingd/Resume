Robotic Arm

Design

Every part of the arm was modeled in SolidWorks before anything was printed or assembled — working out joint clearances, mounting points, and how each link would connect to the next.

V1 — learning the wiring and control

The first version was a single-joint test rig, built to practice wiring and control code before committing to the full arm. It ran on standard hobby servos driven by an Arduino, controlled directly from the Serial Monitor, typing a joint letter and an angle (for example, b90 to send the base to 90°) moved that joint to the given position.

Download V1 code (.ino)

V2 — ESP32 and Bluetooth control

The second version moved to a full multi-joint arm built around STS3215 bus servos, controlled from an ESP32 over Bluetooth using an Xbox controller. The sticks and triggers map to each joint, with a few safeguards built into the control code:

  • Every joint has software position limits, so the arm can't drive itself into its own frame.
  • On boot, every joint moves to a known home position before accepting any input.
  • A controller bumper arms and disarms movement, so the arm stays still until you mean to move it.

Prototyping

Getting the joint housings right took a few print iterations — dialing in tolerances and mounting points before arriving at the parts used in the final build.
